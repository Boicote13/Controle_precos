## Demandas de desenvolvimento

> - Desenvovler o formulario de adição de nota fiscal (CRUD);
> - Uma nota contém diversos items, a página de adição precisar ter essa opção de multiplas escolhas;
> - A interface de inserção dos dados ao banco vai ser no django com formulários simples;
> - A apresentação e interação com os dados vai ser no Streamlist.


- Supermercados devem ter um formulário próprio para inserção no banco. A escolha dele deve ser feita separada dos outros items da nota em um menu com sugestões. Caso o supermercado não esteja disponível um botão vai levar a tela de adição de supermercado. Após adicionar ele deve aparecer disponível para seleção na tela de adição de nota.
